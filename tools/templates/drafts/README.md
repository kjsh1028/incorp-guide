# 초안 틀 (법무지원팀 확인 전)

## request_cnwfoe_ko.docx — 한국 법인의 중국 독자법인 설립 자료요청서 (초안 v0.1, 2026-10-05)
- `make_request_cnwfoe.py` 가 확정 틀 `request_ko.docx` 를 복사해 내용만 바꿔 만든다. 서식(머리, 표, 번호, 글꼴)은 확정본과 같다.
- 노란 `{{빈칸}}`: 사건별 값. 녹색: Claude 초안 중 확인이 필요한 부분(문서를 만들면 표시는 지워진다).
- 법무지원팀 확인본을 받으면: 확인본의 사건 값을 `{{빈칸}}`으로 바꿔 `request_cnwfoe_ko.docx` 를 다시 만들고, 이 스크립트는 지운다. 그 뒤 같은 값으로 docgen.py 결과와 확인본을 비교한다(KR-JSC 때와 같은 방법).

### 확인받을 점 (녹색 부분)
1. 상호: 중국 상호 후보를 3개 받는 것, 지역명·업종 표기를 율촌이 맞추는 것
2. 등록자본: 납입 기한(법정 기한)을 문서에 적지 않고 "율촌이 확인해 안내"로 둔 것
3. 경영범위: 외상투자 제한 여부 검토 문구
4. 등록 주소: 임대차계약 필요, 공유 주소 가능 여부가 지역마다 다르다는 문구
5. 조직 구성: 이사 1인/이사회, 감사 1인/두지 않음 선택지
6. 임원: 법정대표인 선정, 재무책임자·등기 연락원 정보, 휴대전화 실명 인증
7. A 서류 목록·원본 부수·공증 여부(A1~A6 전부)
8. B 서류 목록과 공증·아포스티유 필요 여부(특히 은행 잔고증명/자신증명)
9. 진행 요령: 한국 공증사무소 공증 + 외교부 아포스티유, 제출 기한
10. 진행 순서 표의 기간(지금은 대부분 "—")
11. 해외직접투자 신고(외국환은행)를 송금 전에 해야 한다는 문구
12. 사무실: 임대차계약서와 소유권 증명, 명의 변경 방식, 가상 사무실
13. 자본금 계좌 개설 뒤 송금, 중국 측 실비 청구, 취업 비자·거류 허가
