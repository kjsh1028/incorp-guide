GitHub 연결 (사건 자료 저장)

사건 자료는 비공개 저장소의 cases.json 파일 하나에 저장됩니다. 토큰은 이 기기의 브라우저에만 보관되고 GitHub 말고 다른 곳으로 보내지 않습니다.

토큰 만드는 법
  1. github.com 로그인 → 오른쪽 위 사진 → Settings → 맨 아래 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → 사건 저장소(예: incorp-cases)만 선택
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만든 토큰을 복사해 위 칸에 붙여넣고 "저장하고 연결"

토큰이 만료되면 새로 만들어 다시 붙여넣으면 됩니다. 사건 자료는 그대로 남습니다.
